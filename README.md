# AI Crypto Brain V3

Versión educativa con precios públicos BTC/USD, ETH/USD y SOL/USD y operaciones de práctica ficticias.

## Módulos incluidos
1. Conector de mercado público (solo lectura)
2. Validador de datos
3. Vigilante de conexión y antigüedad de datos
4. Indicadores SMA, EMA y RSI
5. Analizador de tendencia
6. Filtro de volatilidad
7. Generador de señales
8. Gestor de riesgo y exposición
9. Protección de pérdida diaria
10. Cortacircuitos
11. Ejecutor ficticio con comisión y deslizamiento
12. Contabilidad de cartera
13. Stop-loss y objetivo educativos
14. Diario auditable
15. Analítica de resultados
16. Gestor de errores

## Actualizar GitHub Pages
En el repositorio `mi-bot-educativo`, sube y reemplaza `index.html`, `manifest.webmanifest` y `sw.js` con los archivos de esta carpeta. Haz commit de los cambios. GitHub Pages volverá a publicar el sitio.

## Límites
- Solo simulación: sin claves API, cuentas, depósitos ni órdenes reales.
- Los precios proceden de una API pública y pueden fallar, retrasarse o tener límites.
- Los indicadores se forman con observaciones acumuladas mientras la página está abierta.
- El estado de la simulación no se guarda entre sesiones.
- Las reglas son transparentes y didácticas, no una IA que predice el mercado ni una promesa de beneficios.
- No usar este proyecto para operar con dinero real.
